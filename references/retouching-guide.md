# 全品类商品精修指南

在检查目标原图后使用本指南。它主要用于确定结构硬门槛、执行 QA，以及为一次定向纠正选择规则。首轮 Prompt 默认不写材质清单，只有确有高风险时补充一条最关键的结构或材质保护；纠正时最多选择三个具体材质区域，不要把整张表复制进 Prompt。

## 刚性结构与柔性陈列

- 始终锁定原机位、透视、商品朝向、刚性几何和刚性部件相对位置。
- 链条、绳带、线材、肩带、软包装和布料等柔性部件可整理为自然、清晰的商业陈列，但数量、顺序、拓扑、连接点和真实长度必须不变。
- 用户明确要求“摆放不变”时，柔性部件的相对位置也必须保持；无法判断某部件能否活动时按刚性部件处理。
- 不追求会改变结构事实的绝对对称，也不把柔性部件位置变化本身判为失败。

## 颜色与材质分离

- 颜色依据优先级：用户指定的可靠色彩参考、用户确认的商品事实、原图中未过曝且受环境污染较少的区域。通用品类知识不能作为商品颜色依据。
- 材质规则只描述纹理、反射、折射、光泽、透明度和体积感。不要给材质自动添加“暖白”“冷白”“深色”或“高饱和”等颜色。
- 浅色商品保持原有米白、奶油白、暖白、冷白或浅灰倾向；没有可靠依据时只要求中性白平衡和禁止擅自暖化、冷白化、漂白或融入白底。
- 有色商品可补偿拍摄造成的灰暗和低色度，但应锁定原色相与色块边界，避免荧光化、通道溢出或为了鲜艳而换色。
- 透明物体在白底上要依靠真实折射边线、内部结构与受控高光建立层次，不能用灰色填充假装透明，也不能把边缘提亮到消失。

## 材质表现路由

| 识别材质 | 正向表现目标 | 重点保护 |
|---|---|---|
| 布艺、针织、纺织 | 织纹方向清楚，纤维与起伏自然，明暗过渡柔和 | 版型、缝线、印花、真实垂坠与褶皱 |
| 皮革、仿皮、麂皮 | 保留对应皮纹、柔韧折痕和克制光泽，避免蜡感 | 皮纹尺度、压纹、针脚、边油与自然色差 |
| 哑光或半哑光塑料 | 柔和漫反射、低而宽的高光，表面干净但不油亮 | 分模线、按键、磨砂颗粒与真实色块 |
| 亮面塑料、树脂、涂层 | 曲面高光连续受控，颜色有深度，避免廉价塑料感 | 原色相、局部纹理、造型边界、孔位与装饰细节 |
| 软胶、硅胶、橡胶 | 柔性包覆感和自然曲面高光，保留微弱表面阻尼感 | 软硬边界、开孔、防滑纹与接缝 |
| 透明塑胶、亚克力、玻璃 | 轮廓和折射边线明确，内部层次清澈，高光不过曝 | 原始外形、厚度、孔位、气泡、刻面及内部穿线或液体 |
| 珍珠、贝珠、珠光饰面 | 分层珠光柔和清楚，圆润体积自然，不用暖色模拟光泽 | 原始浅色色相、圆度、孔位、表皮纹理与个体差异 |
| 金属 | 按原图保持拉丝、磨砂、镀铬、镜面或低反光类型，净化环境杂乱倒影 | 金属色、轮廓、接缝、螺丝、刻字和表面工艺 |
| 木质、竹质 | 纹理方向连续，天然色差和孔隙真实，光泽符合涂层 | 木纹走向、拼接、边角和真实结疤 |
| 陶瓷、搪瓷、釉面 | 釉面高光平滑、体积饱满，保留真实细微质感 | 器型、口沿、把手、釉色、印花和接缝 |
| 纸张、纸盒、印刷包装 | 纸面纹理克制、折线清楚、印刷边缘干净 | 盒型、刀线、标签排版、颜色块、Logo 和全部可见文字 |
| 液体、凝胶、膏体 | 保持透明度或稠度，液面、气泡与容器折射关系自然 | 容量观感、液位、颜色和容器边界 |

复合材质只在定向纠正时选择实际失败的 1–3 个区域，并分别写明部位；不要无区域地堆叠材质词。

## 品类与结构保护路由

| 品类或结构 | 必须优先锁定的高风险细节 |
|---|---|
| 美妆个护、瓶罐容器 | 瓶型、泵头、喷头、盖子、泵头方向、标签位置与排版、色号、Logo、液位 |
| 鞋服箱包 | 版型、鞋头方向、鞋底厚度、鞋扣、拉链、肩带、走线、面料垂坠和包体比例 |
| 珠宝首饰、链状配件 | 宝石或珠子数量、排列顺序、镶嵌、链节、孔位、连接点、金属色和可见穿线 |
| 数码家电 | 屏幕、按键、接口、线材、插头、面板、缝隙、指示灯和结构比例 |
| 家居家装、家具器皿 | 承托结构、边角、五金、连接处、木纹、皮纹、陶瓷釉面和真实空间比例 |
| 五金工具、机械部件 | 孔位、螺丝、刀口、齿形、接口、卡扣、刻度、金属边缘和功能结构 |
| 食品、印刷包装 | 包装件数、盒袋结构、封口、窗口、标签排版、品牌文字、净含量和必要标识 |
| 玩具、拼装与多部件产品 | 部件数量、关节、卡位、配件归属、左右件关系、印刷图案和连接方式 |

无法归类时，不要强行套用品类模板；使用原图可见事实和通用结构保护规则即可。

## 问题到 Prompt 的映射

- 暗部死黑：提亮暗部结构层次，恢复已有边界、接缝和转折面，不改变原有深色属性。
- 偏色发灰：使用中性白平衡消除环境色污染，恢复有依据的色相和色度，不把全局饱和度作为默认手段。
- 浅色主体融入白底：保留原有浅色色相，以轮廓、微对比、材质纹理和轻接触阴影分离主体，不用描边或灰底。
- 确认属于拍摄环境的灰尘、指纹、油污、胶痕或支架：可以清理；疑似真实划痕、磨损、掉漆或制造痕迹时询问或保留。
- 边缘毛糙：修复抠图残留、锯齿、白黑边和背景色污染，保留毛发、透明、半透明和镂空边缘。
- 重复部件局部变形：只有同图其他同类部件或真实性参考能证明标准形状时才修复，并保持数量、尺寸差异、孔位和连接关系。

## QA 重点

先判定结构硬门槛，再评价商业质感：

1. 原机位、透视、朝向、轮廓、比例、刚性几何和刚性部件位置是否保持；柔性部件按连接事实、真实长度和用户是否要求摆放不变判断。
2. 部件数量、顺序、连接关系、文字、Logo、孔位、接口和功能细节是否一致。
3. 浅色材质是否发生无依据的黄化、蓝化或漂白；有色材质是否灰暗、串色、过饱和或色相漂移。
4. 透明材质是否保持原始外形、厚度、孔位与内部结构，并具有清楚但自然的折射层次。
5. 每个选中的材质区域是否呈现对应的反射、纹理、光泽或体积感，且没有被统一处理成塑料质感。
6. 是否存在局部拉伸、重复纹理、异常反射、边缘破损、孔洞填错、新增物体或大面积灰雾。
7. 主体与接触阴影之外的背景是否为 RGB `(255, 255, 255)`；若需后期合成，是否使用可靠蒙版并避免损伤白色、透明或高光区域。
